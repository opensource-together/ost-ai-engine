# Troubleshooting

## Commandes utiles
- Voir les logs : `docker compose logs`
- Redémarrer les services : `docker compose restart`
- Vérifier la DB : utiliser un client PostgreSQL
- Vérifier les jobs Dagster : interface Dagster

## Problèmes courants
- Variables d’environnement manquantes
- Conflits de ports
- Erreurs Prisma (migrations)
- Problèmes de connexion DB
